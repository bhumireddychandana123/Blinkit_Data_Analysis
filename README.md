# Blinkit_Data_Analysis

## 📌 Project Overview

This project is based on Blinkit sales data analysis using Python. The main purpose of this project is to analyze sales performance based on different product and outlet characteristics.

The analysis focuses on understanding sales across outlet locations, item fat content, item types, and other important factors. Data visualization is used to make the results easier to understand.

## 🎯 Objectives

- Analyze Blinkit sales data using Python.
- Understand sales performance across different outlet locations.
- Compare sales between Regular and Low Fat products.
- Analyze sales across different item types.
- Identify sales patterns based on outlet characteristics.
- Present the analysis using data visualizations.

## 🛠️ Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset

The dataset contains Blinkit product and outlet information.

The main columns used in the analysis are:

- Item Fat Content
- Item Identifier
- Item Type
- Outlet Establishment Year
- Outlet Identifier
- Outlet Location Type
- Outlet Size
- Outlet Type
- Item Visibility
- Item Weight
- Sales
- Rating

## 🔍 Analysis Performed

### 1. Sales by Outlet Location Type

The data is grouped by `Outlet Location Type` and the total `Sales` are calculated.

The outlet locations are categorized into:

- Tier 1
- Tier 2
- Tier 3

The results are sorted from highest sales to lowest sales and represented using a horizontal bar chart.

### 2. Sales by Outlet Location and Item Fat Content

The analysis also compares sales based on two factors:

- Outlet Location Type
- Item Fat Content

The `Sales` values are summed for each combination of outlet location and fat content.

The analysis compares:

- Regular
- Low Fat

This helps understand how Regular and Low Fat products contribute to sales across different outlet locations.

## 📊 Data Visualization

Seaborn and Matplotlib are used to create visualizations.

The project includes a horizontal bar chart to show:

**Total Sales by Outlet Location Type**

The visualization makes it easier to compare sales between different outlet locations.

## 💡 Key Analysis Questions

The project focuses on questions such as:

- What is the total sales by outlet location type?
- Which outlet location type has higher sales?
- How do Regular and Low Fat products contribute to sales?
- How does sales performance differ across outlet locations?
- What patterns can be identified from the sales data?

## 🏁 Conclusion

The Blinkit Data Analysis project uses Python to analyze sales data and understand sales patterns across different outlet locations and product fat categories.

Using Pandas for data manipulation and Matplotlib and Seaborn for visualization, the project converts raw sales data into easy-to-understand visual information.

The analysis provides a basic understanding of how outlet location and item fat content are related to sales performance.
